# agentic-workflow

How work is planned, done, judged and escalated. This plugin will hold the ticket spec, decomposition guidance, the escalation policy, the QA skill (`qa-ticket`), the implementer and reviewer briefs, the verify gate, and the nightly orchestrator.

Requires: superpowers plugin; git, gh, python3. Depends on no other plugin. Full list: `REQUIREMENTS.md` at the repo root.

Install: `/plugin marketplace add ImHereForTheCookies/agent-toolkit`, then `/plugin install agentic-workflow@agent-toolkit`
