# agent-toolkit

A Claude Code plugin marketplace for agentic workflow, code navigation, Linear integration and project scaffolding.

Install: /plugin marketplace add ImHereForTheCookies/agent-toolkit

## Ticket loop

`plugins/ticket-loop` is a general, unattended job: Linear tickets carry a Skill label (design, plan, build, evaluate) and the job routes each to a skill. Design docs live in Notion, code in GitHub. See `plugins/ticket-loop/README.md` to set up a project or run it yourself.
